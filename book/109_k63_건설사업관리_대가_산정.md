## 63. 건설사업관리 대가 산정

제7부 학교공사 계약·인허가 쟁점 · 63

건설사업관리 대가 산정

실비정액가산방식 — 직접인건비 + 제경비(110~120%) + 기술료(20~40%) + 직접경비

한마디로

건설사업관리(감리) 용역비를 얼마로 할지 정하는 기준입니다. 「건설엔지니어링 대가 등에 관한 기준」(국토교통부 고시)에 따라 업무별 투입인원수로 직접인건비를 구하고, 여기에 제경비·기술료·직접경비를 더하는 실비정액가산방식으로 산정합니다. 투입인원수는 공사비 규모·건설사업관리기간·골조공사비 비중을 반영한 공사난이도와 보정계수에 따라 달라지므로, 공사비와 기간을 정확히 넣는 것이 출발점입니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 대가에 넣는 공사비는 총예정금액(예정가격 결정의 근거가 되는 금액)에서 용지비·보상비·법률수속비·부가가치세를 뺀 금액입니다 — 낙찰률을 곱한 계약금액이 아닙니다(「건설엔지니어링 대가 등에 관한 기준」 제2조제5호·제6호).

| | |
| --- | --- |
| 언제 | 감독 권한대행 등 건설사업관리 용역을 발주하기 전 용역비를 산정할 때, 그리고 설계변경·공사기간 변경으로 대가를 조정할 때 문제 됩니다. |
| 누가 | 발주청 사업 담당자가 산정하며, 제경비율(직접인건비의 110~120%)과 기술료율((직접인건비+제경비)의 20~40%)은 그 범위 안에서 발주청이 정합니다. |
| 무엇을 | 공사비(관급자재 포함, 용지비·보상비·법률수속비·부가가치세 제외)와 건설사업관리기간으로 공사난이도를 구하고, 업무별 기준인원수에 적용수량·보정계수·난이도를 곱해 투입인원수를 산정합니다. 노임단가를 곱한 직접인건비에 제경비·기술료·직접경비를 더해 공급가액을 내고, 손해배상공제비용과 부가가치세를 더합니다. 직접경비는 실제 소요비용으로 정산한다는 내용을 계약문서와 과업지시서에 적습니다(제11조2). |

### 처음 맡았다면

- 공사비에서 용지비·보상비·법률수속비·부가세 빼기(관급자재는 포함)
- 건설사업관리기간·골조공사비 비중 확인
- 업무별 투입인원수와 배치계획 대조
- 직접경비 실비정산 문구를 계약문서에 넣기

주의

- 추정공사금액으로 대가를 산출했다면 시공이후단계 대가를 예정가격 근거 금액으로 변경한다는 내용을 계약서류에 적어야 합니다(제7조2). #질의회신(감리용역비 산출)
- 설계변경으로 공사금액이 당초보다 10% 이상 늘거나 줄면 대가를 조정할 수 있으며, 물가변동분은 빼고 당초 총예정금액 기준으로 환산합니다(제7조1 2).
- 공사가 예정가격의 70% 미만으로 낙찰되면 시공단계 건설사업관리기술인을 추가 배치해야 합니다 — 낙찰률 65% 이상 70% 미만 20%, 60% 초과 65% 미만 30%, 55% 초과 60% 미만 40%, 55% 이하 50% 추가, 추가 인원 중 1명 은 발주청이 정하는 특정분야 자격·경력자(같은 기준 제9조2 2호).
- 대가 산정의 '공사비'는 부가가치세를 빼지만, 감독 권한대행 대상 판단의 총공사비는 부가가치세를 포함한 예정공사비로 봅니다. #질의회신(건설기술 진흥법 건설사업관리 대상 설계용역 공사비 기준)

용어 풀이

- **실비정액가산방식** : 직접인건비·직접경비·제경비·기술료 등을 합산해 대가를 산출하는 방식
- **투입인원수** : 업무에 투입되는 기술인 인원(고급기술자 기준 인·일)
- **공사난이도** : 공사비 규모·기간·골조 비중에 따라 업무량을 조정하는 계수
- **기술지원기술인** : 현장에 상주하지 않고 기술 검토를 지원하는 건설사업관리기술인
- **직접경비** : 주재비·출장여비·차량운행비 등 실제 소요비용으로 정산하는 경비

건설사업관리(감독 권한대행 등) 대상과 용역 대가를 정하는 '총공사비'는 아래와 같이 봅니다.

근거 조문

- 감독 권한대행 등 건설사업관리 의무 대상은 '총공사비 200억원 이상으로 별표7에 해당하는 건설공사'(시행령 제55조제1항제1호), 건설사업관리 대상 설계용역은 '총공사비 300억원 이상 건설공사의 기본·실시설계용역'(제57조제4호)입니다.
- 두 조문은 총공사비를 따로 정의하지 않고, 정의는 제89조제1항제1호에 있습니다: '도급자가 설치하는 공사의 관급자재비를 포함하되, 토지 등의 취득·사용에 따른 보상비는 제외한 금액'(현행 2026. 6. 9. 시행본).

대상 판단 총공사비

- 국토부는 건설사업관리 대상 설계용역의 총공사비에 제89조제1항제1호 정의를 적용하고, 이전 단계 용역에서 산출한 사업비의 부가가치세를 포함한 예정공사비로 본다고 회신했습니다. #질의회신(건설기술 진흥법 건설사업관리 대상…)
- 같은 정의를 적용하므로 시공사(도급자)가 설치하는 관급자재비는 넣고 보상비는 뺍니다.
- 관급자(발주청)가 직접 설치하는 관급자재비는 품질관리 대상 판단에서 제외된다고 회신했으나 #질의회신(품질계획 수립시 총공사비에 관급자설치…) #질의회신(공사 진행중 설계 변경에 따른 공사비…), 건설사업관리 대상 판단에서 관급자 설치분 제외를 직접 다룬 회신은 찾지 못했습니다.
- 금액이 기준선 근처라면 발주 전에 국토부 건설안전과에 확인해 두십시오.

용역 대가 산정 총공사비

- 건설사업관리 용역비는 보상비를 제외하고 관급자재를 포함한 총공사비로 시공단계 건설사업관리기간을 산정하므로 관급자재를 포함해 산정합니다.
- 추정공사금액으로 계약했다면 예정가격 결정의 근거 금액으로 변경계약한다는 내용을 계약서에 적고, 설계변경으로 공사금액이 10% 이상 증감하면 당초 총예정금액 기준으로 환산해 대가를 다시 작성합니다(물가변동분 제외). #질의회신(감리용역비 산출)

관련 기준

- 시공평가 대상(총공사비 100억원 이상)의 총공사비는 관급자재비를 포함한 공사예정금액입니다. #질의회신(감독권한대행 등 통합건설사업관리…)
- 책임건설사업관리기술인 경력·배치는 총공사비 100억 ·300억 ·500억원 구간으로 정합니다. #질의회신(책임건설사업관리기술자 배치기준)
- 설계변경으로 공사비가 늘어도 대상 구분은 당초금액 기준입니다. #질의회신(품질관리계획 수립 대상인 공사 시행 중…)

혼동 주의

- 건축사법에 따른 공공건축 감리대가의 '공사비'는 용지비·보상비·법률수속비·부가가치세를 뺀 금액(관급자재대는 포함)으로, 건설기술 진흥법 총공사비와 부가가치세 처리가 다릅니다. #질의회신(운동장 잔디공사 용역비 산출)
- 품질관리계획 대상 총공사비는 '품질관리계획 대상 총공사비 산정 기준' 주제를 함께 보십시오.

건설사업관리 대가 한눈에 보기 — 건설엔지니어링 대가 등에 관한 기준(국토교통부 고시)

| 구분 | 내용 |
| --- | --- |
| 산정 방식 | 실비정액가산방식 — 직접인건비 + 제경비 + 기술료 + 직접경비(+추가업무비용) + 손해배상보험(공제)료 + 부가가치세 (제2조제2호) |
| 공사비 | 총예정금액(자재대 포함)에서 용지비·보상비·법률수속비·부가가치세를 뺀 금액. 총예정금액은 예정가격 결정의 근거가 되는 금액 (제2조제5·6호) |
| 직접인건비 | 투입인원수(고급기술자 기준, 인·일) = 기준인원수 × 적용수량 × 보정계수 × 공사난이도 → 노임단가를 곱해 산정 |
| 기술지원기술인 | 시공단계 투입인원수 × 비율(단순 10% · 보통 15% · 복잡 20%) — 별표2 제1호 바목 |
| 제경비 · 기술료 | 제경비는 직접인건비의 110~120% (제12조), 기술료는 (직접인건비 + 제경비)의 20~40% (제13조) |
| 직접경비 | 상주기술인 주재비 = 상주 직접인건비의 30%, 기술지원기술인 출장여비 = 기술지원 직접인건비의 10% (도서·산간 등은 증감 가능), 현지 차량운행비(1,000억 원 미만 1대), 현지사무원, 보고서 인쇄비 — 실제 소요비용으로 정산(제11조, 별표2 제3호) |

건축분야 보정계수와 공사난이도 — 별표2 제2호 다목

| 항목 | 값·산식 |
| --- | --- |
| a. 건축용도 | 단순 0.9 · 보통 1.0 · 복잡 1.1 |
| b. 공사성격 | 신축 1.0 · 전면 리모델링(증축 포함) 1.1 · 순환 리모델링 1.2 |
| c. BIM 적용 | 미적용 1.0 · 적용 1.1 |
| 시공단계 난이도 | 0.011C(1−0.0025C) + 기간보정계수 + 0.5 × 골조공사비 비중 + 0.2 (총공사비 2,000억 원 이하) |
| 시공전단계 난이도 | 0.015C(1−0.001C) |
| 기간보정계수 | (평균 건설사업관리기간 − 해당 공사 기간) ÷ 평균 기간 × 0.1 — 평균 기간은 별표2 제1호 라목 표에서 직선보간 |
| C(총공사비) | 10억 원 단위, 전기·통신·소방 공사비 제외. 50억 원 이하·2,000억 원 초과는 별도 산식 |

시공단계 안전관리의 보정계수·난이도는 1.0 이상만 적용합니다. 제경비율·기술료율은 범위 안에서 발주청이 정합니다. 기술지원기술인 인건비는 직접인건비에 포함됩니다 #질의회신(건설사업관리 용역 준공정산 기준). 공사난이도의 총공사비(C)는 예정가격 근거 금액으로 넣고, 낙찰률을 곱한 금액을 넣지 않도록 주의하십시오.

현장 에피소드 지은이가 겪은 일

처음 건설사업관리 용역비를 뽑아 보고 깜짝 놀랐습니다. "공사비 100억 에 감리비가 이렇게 많이 나와?" 그런데 그 숫자 하나하나가 현장에 상주하며 검측하고, 안전을 살피고, 품질을 확인할 사람의 몫이었습니다. 감리비는 아끼는 돈이 아니라 안전한 현장을 위한 길입니다. 다만 산식을 처음 펴면 0.011C(1−0.0025C)… 고등학교 미적분보다 더 놀랄 수 있습니다. 투입인원수, 보정계수, 공사난이도, 기간보정계수까지 — 하나만 잘못 넣어도 금액이 훌쩍 달라집니다. 「건설엔지니어링 대가 등에 관한 기준」을 파고 또 파고, 조문과 별표를 옆에 펴 놓고 한 칸씩 확인해야 틀리지 않습니다.
