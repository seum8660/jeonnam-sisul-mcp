## 67. 건축허가·신고와 대수선·증축 구분

제7부 학교공사 계약·인허가 쟁점 · 67

건축허가·신고와 대수선·증축 구분

공사 성격별 허가·신고 절차를 고르는 기준

한마디로

학교 건물을 고칠 때 그 공사가 증축인지, 대수선인지, 개축인지에 따라 허가·신고 절차가 달라집니다. 건축면적·연면적·층수·높이가 늘면 증축이고, 면적이 늘지 않아도 기둥·보·내력벽·주계단 등을 고치면 대수선이 될 수 있습니다. 구분을 잘못하면 필요한 허가 없이 공사하게 됩니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 면적을 늘리지 않아도 대수선일 수 있습니다. 기둥·보·지붕틀 3개 이상, 내력벽·외벽 마감재 30㎡ 이상을 수선·변경하거나 방화구획·주계단을 고치면 대수선이므로 허가·신고 대상인지 먼저 확인합니다(건축법 시행령 제3조의2).

| | |
| --- | --- |
| 언제 | 리모델링, 엘리베이터 설치, 가설건축물 설치처럼 기존 건물에 손을 대는 공사를 계획할 때 문제 됩니다. |
| 무엇을 | 면적 증가 여부와 주요 구조 변경 여부를 따져 공사 성격(증축·개축·대수선)을 정하고, 신고 대상 여부는 증축·개축·재축은 늘리거나 고치는 부분의 바닥면적으로, 대수선은 건물 전체 규모로 판단합니다. |

### 처음 맡았다면

- 면적·층수·높이 증가 여부 확인
- 기둥·보·내력벽 변경 여부 확인
- 기존 건축물 전체 규모 확인
- 방화구획 변경 수반 여부 확인

주의

- 신고 대상 판단 기준은 유형마다 다릅니다. 증축·개축·재축은 늘리거나 고치는 부분의 바닥면적(85㎡ 이내, 3층 이상 건물은 연면적의 1/10 이내)으로, 대수선은 건물 전체 규모(연면적 200㎡ 미만·3층 미만)로 판단합니다(건축법 제14조1).
- 내력벽·기둥·보·지붕틀 중 셋 이상 철거 후 재축조는 개축입니다.
- 철골 기둥·보 구조는 가설건축물 컨테이너로 보기 어렵습니다.

용어 풀이

- **증축** : 기존 건물의 면적·층수·높이를 늘리는 것
- **대수선** : 기둥·보·내력벽 등 주요 구조나 외형을 고치는 것
- **개축** : 주요 구조 셋 이상을 철거하고 같은 규모로 다시 짓는 것
- **허가권자** : 건축허가를 내주는 시장·군수·구청장

더 깊이 보기 질의회신 해설

아래 내용은 질의회신을 바탕으로 정리한 해설입니다. 법령 원문이 아니며, 문단 끝 #질의회신(제목 키워드)으로 근거를 적었습니다. 치트키 질의회신 검색에서 키워드로 원문을 찾을 수 있습니다.

대수선인지 증축인지는 면적 증가 여부로 먼저 갈립니다.

- 기존 건축물이 있는 대지에서 건축면적·연면적·층수 또는 높이를 늘리면 증축이고, 대수선은 그 어디에도 해당하지 않는 것을 말하므로 건축면적이 늘어난다면 증축에 해당한다고 보았습니다. #질의회신(대수선에 해당되는 지 여부)
- 반대로 면적이 늘지 않더라도 기둥·보·내력벽·주계단 등의 구조나 외부 형태를 수선·변경·증설하는 행위라면 대수선이 될 수 있습니다. #질의회신(건축물 대수선 여부)
- 엘리베이터 설치가 방화구획의 해체나 변경을 수반하면 대수선에 해당할 것으로 본 회신도 있습니다. #질의회신(4층 건축물에 엘리베이터 신규 설치가…)

신고로 갈음할 수 있는 대수선의 범위를 판단할 때 기준이 되는 규모는 고치려는 부분이 아니라 기존 건축물 전체입니다.

- 연면적 200제곱미터 미만이고 3층 미만인 건축물에서의 대수선에 한한다고 명시한 회신이 있습니다. #질의회신(대수선 해당 여부의 건축물 규모 판단은)
- 10층 건물의 일부 150제곱미터를 고치는 경우를 신고 대상으로 오해하기 쉬운 지점입니다.

공사 중 변경이 생겼을 때는 사용승인 시 일괄신고가 가능한지를 보십시오. 기둥을 세 개 이상 변경하는 것은 대수선이고, 건축 중인 건축물에 대수선 사유가 생기면 사용승인 신청 시 일괄신고할 수 있다고 보았습니다. #질의회신(설계변경에 대한 건축허가 변경시기)

- 다만 내력벽·기둥·보·지붕틀 중 셋 이상을 철거하고 종전과 같은 규모로 다시 짓는 행위라면 개축으로 보아야 한다는 점을 함께 짚고 있습니다. #질의회신(건축공사 설계변경)
- 일괄신고 기준인 바닥면적 합계 50제곱미터 이하는 증가분과 감소분을 합산한 결과를 말합니다. #질의회신(설계변경시 면적산정은 증·감부분의…)

가설건축물에서는 컨테이너의 범위가 자주 문제됩니다.

- 공장에서 제작된 컨테이너나 조립식 판넬구조를 말하며, 일반 건축물처럼 기둥·보 형식의 철골구조라면 이에 해당한다고 보기 어렵다고 정리되어 있습니다. #질의회신(가설건축물 조항 중 컨테이너 또는 이와…)

허가 취소와 관련해서는, 착수하지 않았거나 완료가 불가능하다고 인정되면 허가권자가 취소하도록 하고 있으며 취소 전에 부지조성 부분을 원상복구하도록 하는 명시 규정은 없다고 보았습니다. #질의회신(건축허가 취소)

이 주제의 회신은 대부분 개별 사안의 최종 판단이 허가권자인 시장·군수·구청장의 권한이라는 점을 함께 적고 있습니다.

- 도면을 갖추어 허가권자와 먼저 협의하시는 편이 빠릅니다.

건축 행위 용어 정의 — 건축법 시행령 제2조·제3조의2

| 용어 | 뜻 |
| --- | --- |
| 신축 | 건축물이 없는 대지(기존 건축물을 해체·멸실한 대지 포함)에 새로 짓는 것 |
| 증축 | 기존 건축물이 있는 대지에서 건축면적·연면적·층수·높이를 늘리는 것 |
| 개축 | 내력벽·기둥·보·지붕틀 중 셋 이상을 포함해 해체하고 종전 규모 범위에서 다시 짓는 것 |
| 재축 | 천재지변 등 재해로 멸실된 건축물을 종전 연면적 이하로 다시 짓는 것 |
| 이전 | 주요구조부를 해체하지 않고 같은 대지의 다른 위치로 옮기는 것 |
| 대수선 | 증축·개축·재축이 아니면서 1 내력벽 증설·해체 또는 30㎡ 이상 수선·변경 2 기둥 3 보 4 지붕틀을 증설·해체 또는 3개 이상 수선·변경 5 방화벽·방화구획 바닥·벽 6 주계단·피난계단·특별피난계단 증설·해체·수선·변경 7 다가구·다세대 경계벽 8 외벽 마감재료 증설·해체 또는 30㎡ 이상 수선·변경 |

교육청이 짓는 학교 건물은 허가·신고가 아니라 건축협의 대상이지만, 협의할 때도 공사 성격(신축·증축·대수선 등)과 허가·신고 기준을 같은 방식으로 따집니다.
