## 78. 농지전용 — 학교 부지에 논·밭이 있을 때

제7부 부지와 인허가 · 78

농지전용 — 학교 부지에 논·밭이 있을 때

부지에 논·밭이 있으면 — 협의·의제와 부담금 감면

한마디로

논·밭·과수원 같은 농지를 학교 부지로 쓰려면 농지를 다른 용도로 바꾸는 「농지전용」을 거칩니다. 도시지역이면 도시계획시설 결정 때 협의하고, 도시지역 밖이면 학교시설사업 시행계획 승인 때 허가가 의제됩니다. 국·공립학교는 농지보전부담금이 전액 감면됩니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 농지보전부담금이 감면되어도 농지전용 협의·허가 절차 자체는 거쳐야 합니다(농지법 제34조, 시행령 별표 2).

| | |
| --- | --- |
| 언제 | 부지를 정하고 도시계획시설 결정이나 시행계획 승인을 준비할 때 확인합니다. |
| 무엇을 | 부지 안 농지의 지목·면적·농업진흥지역 여부를 확인하고, 협의 서류를 갖추고, 부담금 감면 여부를 확인합니다. |

### 처음 맡았다면

- 토지대장에서 전·답·과수원 필지 확인
- 농업진흥지역(진흥구역·보호구역)인지 확인
- 도시지역 안인지 밖인지 확인
- 국·공립학교 부담금 100% 감면 확인
- 면적·경계가 바뀌면 변경허가
- 청사·관사 등 학교가 아니면 직접 허가 신청, 부담금 50% 감면

### 대상과 기준

**학교 부지에 논·밭·과수원이 들어 있으면** 농지를 다른 용도로 바꾸는 「농지전용」을 거칩니다. 공립학교는 대개 **도시계획시설 결정 때 협의** 하거나 **학교시설사업 시행계획 승인 때 허가가 의제** 되어, 교육청이 따로 허가증을 받는 일은 드뭅니다. 대신 협의에 필요한 서류는 교육청이 준비합니다.

부지가 어디에 있느냐로 갈립니다

도시지역

주거·상업·공업·녹지지역

도시지역 밖

관리·농림·자연환경보전지역

언제

도시·군계획시설(학교) **결정할 때** 농림축산식품부장관과 미리 협의

학교시설사업 **시행계획 승인** 때 농지전용허가 의제 협의

누가

결정권자(시장·군수 등)가 협의 요청

승인권자(교육청)가 관할 시장·군수·구청장을 거쳐 협의

그 뒤

협의를 거친 도시지역 농지는 **따로 허가 없이** 전용 (법 제34조1 2)

의제 협의가 끝나면 허가를 받은 것으로 봄

예외

이미 지정된 주거·상업·공업지역에 결정하면 협의 대상 아님 (법 제34조2 1 단서)

계획관리지역 지구단위계획구역은 지정 때 협의 (법 제34조2 1의2)

근거

농지법 제34조2 1

농지법 제34조1, 학교시설사업 촉진법 제5조

### 절차와 농지보전부담금

부지 안 농지 확인 → 협의(또는 허가) 서류 작성 → 시장·군수·구청장 제출 → 농지보전부담금 감면 확인 → 협의·허가 → 전용

**농지 확인** 토지대장 지목(전·답·과수원)과 실제 이용 현황을 함께 확인 — 농업진흥지역(진흥구역·보호구역)인지도 확인

**제출처** 농지전용허가신청서와 첨부서류를 해당 농지 소재지 **시장·군수·자치구청장** 에게 제출 (시행령 제32조1)

**부담금 산정** 개별공시지가 × **30%** (농업진흥지역) 또는 **20%** (그 밖) — ㎡당 상한은 농림축산식품부령, 부담금이 있으면 허가(의제 포함) 전까지 납부 (시행령 제53조, 법 제38조4)

**학교는 감면** 전용 신청자가 직접 설치하는 **국·공립학교(유·초·중등·고등)는 100% 감면** (시행령 별표 2 제3호 노목) — 감면이 되어도 신청 절차는 거침

### 학교가 아닐 때 — 청사·관사·수련원 등

**의제는 「학교시설」에만 붙습니다.** 농지전용허가 의제(학교시설사업 촉진법 제5조6호)는 같은 법 제2조의 학교시설(교사대지·체육장, 교사·체육관·기숙사·급식시설 등) 사업에만 적용됩니다. 청사·직속기관·관사처럼 학교시설이 아니면 **농지전용허가를 직접 신청** 하거나 도시계획시설 결정 때 협의합니다.

학교와 학교가 아닌 시설 비교

학교시설

유·초·중·고 교사·체육장 등

학교가 아닌 시설

청사·직속기관·관사 등

절차

시행계획 승인 때 **허가 의제** (학교시설사업 촉진법 제5조6호)

시장·군수·구청장에게 **농지전용허가 직접 신청** (시행령 제32조1) 또는 도시계획시설 결정 때 협의

부담금 감면

**100%** — 국·공립학교 (별표 2 제3호 노목)

**50%** — 국가·지자체가 설치하는 공용·공공용 시설 (별표 2 제1호 다목)

납부

감면되면 낼 금액 없음

남은 50% 를 허가 **전까지** 납부 (법 제38조4)

허가(의제 협의 포함)는 누가 하나 — 면적 기준

**시장·군수·구청장** 농업진흥지역 안 **3천㎡ 미만**, 밖 **3만 ㎡ 미만** (시행령 제71조2 1)

**시·도지사** 농업진흥지역 안 3천㎡ 이상 3만 ㎡ 미만, 밖 3만 ㎡ 이상 30만 ㎡ 미만 (시행령 제71조1 1) — 그보다 넓으면 농림축산식품부장관

**해석** 공립 교육기관은 시·도가 설치하는 시설로 보아 50% (별표 2 제1호 다목)를 적용했습니다. 관사처럼 공용성이 약한 시설은 관할 시·군 농지 부서와 미리 확인하세요.

원문 대조 2026. 11. 13. — 농지법 제34·38조(2026. 9. 18. 시행), 같은 법 시행령 제32·53·71조·별표 2(2026. 9. 18.), 학교시설사업 촉진법 제2·5조(2025. 11. 11.)

용어 풀이

- **농지전용** : 농지를 농작물 경작 외의 용도로 쓰는 것
- **농업진흥지역** : 농업을 보호하려고 지정한 지역(진흥구역·보호구역)
- **농지보전부담금** : 농지를 전용할 때 내는 부담금 — 국·공립학교는 100% 감면
