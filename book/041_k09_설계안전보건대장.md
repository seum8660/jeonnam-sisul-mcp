## 9. 설계안전보건대장

제2부 설계 · 9

설계안전보건대장

설계 단계 위험요인·감소대책을 담는 문서

한마디로

총 공사금액 **50억원 이상** 공사에서 설계자가 발주청의 기본안전보건대장을 반영해 설계 단계 안전보건 사항을 정리한 문서입니다. 교육청은 이를 받아 검토하고 시공자에게 넘겨 줍니다.

치트키 · 꼭 알아야 할 것

- **기준** 공사비 50억 이상
- **놓치기 쉬운 것** 입찰 때 고지 누락 — 입찰 시 미리 알리고 계약 때 수급인에게 줘야 합니다

| | |
| --- | --- |
| 언제 | 설계 단계, 기본안전보건대장 작성 후에 설계자가 작성합니다. |
| 무엇을 | 설계자가 작성해 안전보건 전문가 검토 후 제출하면, 교육청은 입찰 때 이를 미리 알리고 계약 체결 시 수급인에게 제공합니다. |

### 처음 맡았다면

- 기본안전보건대장 반영 여부 확인
- 입찰공고에 대장 고지
- 계약 시 수급인에게 제공

### 대상과 기준

50억 원↑

총공사금액 50억 원 이상 건설공사

시간·장소가 떨어진 공사를 일정 기간 총액으로 계약했다면 개별 공사금액 50억 원 이상일 때 적용

「산업안전보건법」 제67조, 건설공사 안전보건대장의 작성 등에 관한 고시 제3조·제6조

설계안전보건대장이 넘어가는 길

기본안전보건대장 반영 → 설계자 작성 → 안전보건 전문가 검토 → 발주자 제출 → 입찰 때 고지 → 계약 때 수급인에 제공

누가, 언제, 무엇을 — 설계 대장에서 공사 대장으로

설계안전보건대장

설계자 · 설계단계

계획서 **위험요인과 감소방안을 정함** - 적정 공사기간·공사금액 산출서
- 유해·위험요인과 감소방안
- 산업안전보건관리비 산출내역서

발주자: 작성하게 하고 확인

↓

공사안전보건대장

최초 수급인(원도급 시공사) · 착공 전

이행계획서 **감소방안을 현장에서 실행** - 감소방안 반영 안전보건 조치 이행계획
- 유해위험방지계획서 조치내용
- 건설기계 배치·이동계획
- 재해예방 기술지도 결과

발주자: 작성하게 하고 이행 여부 확인

✔ 두 대장 모두 발주자가 안전보건 분야 전문가에게 적정성을 확인받아야 합니다(법 제67조2).
✔ 설계 건설사업관리에서 공기·공사비 적정성을 이미 검토했다면 산출서를 생략할 수 있습니다.

대장별 포함 사항: 「산업안전보건법 시행규칙」 제86조2 3

#질의회신(관급자재 안전보건대장 작성 대상…) · 한국산업안전보건공단 · 2025.05.29

주의

시간·장소가 서로 떨어진 여러 공사를 일정 기간 묶어 총액으로 계약했다면, 총액이 아니라 개별 공사금액이 50억원 이상인 공사에만 적용합니다(안전보건대장 고시 제3조2)

용어 풀이

- **수급인** : 공사를 맡아 하기로 계약한 업체(시공자)
- **총액 계약** : 시간적·장소적으로 분리된 여러 공사를 일정 기간 묶어 한 번에 총액으로 맺는 계약(예: 연간 단위 보수공사)
