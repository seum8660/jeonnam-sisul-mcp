## 60. 공동도급 — 공동이행·분담이행과 계약해지

제7부 학교공사 계약·인허가 쟁점 · 60

공동도급 — 공동이행·분담이행과 계약해지

함께 맡는 계약 — 누가 어디까지 책임지나

한마디로

두 곳 이상의 업체가 하나의 공동수급체를 만들어 공사를 함께 맡는 계약입니다. 지분(출자비율)대로 공사 전체를 함께 책임지는 공동이행방식과, 공종을 나눠 자기 몫만 책임지는 분담이행방식이 있습니다. 어느 방식이냐에 따라 구성원이 부도났을 때와 계약을 해지할 때의 처리가 완전히 달라집니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 공동이행에서는 한 구성원이 부도나도 잔존구성원이 공사 전체를 이행할 책임이 있습니다(집행기준 「공동계약 운영요령」).

| | |
| --- | --- |
| 언제 | 입찰공고에 공동계약 이행방식을 정할 때, 그리고 공사 중 구성원이 부도·포기하거나 지분 변경을 요청할 때 문제 됩니다. |
| 누가 | 발주기관 계약 담당자가 입찰공고에 이행방식을 정하고, 지분 변경·구성원 추가·탈퇴는 구성원 연명 요청을 받아 승인합니다. |
| 무엇을 | 공동이행은 구성원 전원이 연대해 공사 전체를 책임지고, 분담이행은 각자 분담부분만 책임집니다. 구성원이 이행하지 못하면 방식에 따라 잔존구성원 이행 또는 보증기관 청구로 처리합니다. |

### 처음 맡았다면

- 입찰공고·계약서의 이행방식 확인하기
- 구성원별 면허·지분율(5% 이상) 확인하기
- 대가 신청서가 구성원별로 나뉘었는지 확인하기
- 부도 시 1개월 안에 지분 조정·보증시공 결정하기
- 협정서 변경은 사전승인으로만 처리하기

### 대상과 기준

법령이 정한 것

**두 가지 방식** 공동계약을 맺을 때 공동수급체 구성원에게 **공동으로 이행** 하게 하거나 **분담하여 이행** 하게 할 수 있음 — 세부사항은 행정안전부장관이 정함 (「지방자치단체를 당사자로 하는 계약에 관한 법률 시행령」 제88조제1항)

**자격** 공동이행은 구성원 모두가 계약 전체에 필요한 면허·등록을 갖춰야 하고, 분담이행은 **자기 분담부분** 에 필요한 면허·등록만 갖추면 됨 (같은 조 제3항)

한눈에 비교 — 집행기준 「공동계약 운영요령」

| 구분 | 공동이행방식 | 분담이행방식 |
| --- | --- | --- |
| 나누는 기준 | **출자비율** (지분율) | **분담내용** (공종·구간) |
| 발주자에 대한 책임 | 구성원 전원이 **연대** 해서 책임 | 각자 **자기 분담부분만** 책임 |
| 하도급 | 다른 구성원의 동의를 받아야 함 | 자기 책임 아래 분담부분 일부를 하도급할 수 있음 |
| 최소지분율 | 5% 이상(미달하면 입찰무효) | 5% 기준의 예외 |
| 어울리는 공사 | 같은 업종 업체가 지역업체 참여·규모 때문에 함께 하는 공사 | 건축+설비처럼 업종이 다른 공사를 묶는 경우 |

공통 — 계약서는 전원 연명 서명, 기성·준공대가는 구성원 각자에게 지급 · 그림은 가상의 예시

### 구성원이 이행하지 못할 때 · 계약해지

공통 기준 — 집행기준 제11장 제9절

**해지·해제 사유** 공사이행보증회사에 **보증시공을 청구** 하거나 공동수급체 구성원에게 **잔여공사를 완성** 하게 할 수 있음 — 파산·부도로 준공기한 내 완성이 어려우면 계약상대자 동의 없이도 가능

**구성원 부도 등** 발생일부터 **1개월 이내** 에 그 구성원의 잔여 출자비율을 조정하거나 보증시공을 청구할 수 있음

**정당한 이유 없는 불이행** 발주기관장과 잔여구성원 전원이 요청하면 탈퇴조치할 수 있음

방식별로 달라지는 것

| 상황 | 공동이행방식 | 분담이행방식 |
| --- | --- | --- |
| 구성원 일부 부도·포기 | 잔존구성원이 **연대해 공사 전체** 를 이행할 의무 — 출자비율 변경·구성원 추가로 이어감 | 그 구성원의 **분담부분만** 문제 됨 |
| 보증기관 청구 | 잔존구성원이 요건을 못 갖추거나, 갖추고도 이행하지 않을 때 | 잔존구성원 자격과 관계없이 **바로 청구** (집행기준 제1장 제5절) |
| 지체상금 | 공사 **전체** 계약금액 기준으로 전원 부담 | 지체를 일으킨 구성원이 **자기 분담부분만** 부담(대법원 판례) |
| 선금 반환 | 다른 구성원의 선급금 반환채무까지 연대하지 않음(대법원 판례) | 구성원별로 각자 정산 |
| 지분 정리 | 탈퇴자 지분은 잔존구성원에게 나눠 더함 — 한 구성원 지분 전부를 다른 1인에게 넘기는 것은 불가 | 분담내용 변경 또는 보증시공으로 정리 |

해지하기 전에 이 순서로 확인합니다

**1. 이행방식** 계약서·입찰공고에 적힌 방식부터 확인 — 방식에 따라 책임 범위가 완전히 달라짐

**2. 잔존구성원** 공동이행이면 잔존구성원이 이행할 의사와 요건이 있는지 서면으로 확인 — 해지보다 먼저

**3. 보증서** 보증서는 구성원별로 따로 발급되는 경우가 많으므로 어느 구성원의 보증기관에 청구할지 정함

**4. 승인 절차** 출자비율 변경·구성원 추가·탈퇴는 구성원 연명 요청 → 계약담당자 승인 — 협정서는 사전승인 없이 못 바꿈

**해석이 필요한 부분** 공동이행은 잔존구성원이 이행하면 전체 해지 사유가 되기 어렵고, 분담이행은 문제 된 분담부분만 정리하면 나머지 계약은 유지된다고 봅니다(법령 문장 아님 — 계약부서·법률 자문과 판단).

원문 대조 2026. 11. 11. — 「지방자치단체를 당사자로 하는 계약에 관한 법률 시행령」 제88조(현행). 「지방자치단체 입찰 및 계약 집행기준」 제1장 제5절·제6장·제11장 제9절은 예규 제372호(2026. 7. 1. 시행) 기준 (현행 제395호 원문 확인 필요), 지체상금·선금은 대법원 판례

용어 풀이

- **공동수급체** : 공동계약을 위해 2개 이상 업체가 만든 하나의 수급 단위
- **출자비율** : 공동이행방식에서 구성원별 지분(%)
- **보증시공** : 구성원이 이행하지 못할 때 보증기관이 대신 공사를 완성하게 하는 것
