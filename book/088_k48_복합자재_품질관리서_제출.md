## 48. 복합자재 품질관리서 제출

제5부 준공 · 48

복합자재 품질관리서 제출

샌드위치패널 등 자재 성능을 확인하는 서류

한마디로

화재 때 불이 번지지 않도록 복합자재·단열재·방화문 같은 자재가 성능 기준에 맞게 쓰였는지 서류로 증명하는 것입니다. 사용승인을 신청할 때 함께 제출합니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 품질관리서를 제출하지 않거나 거짓으로 제출하면 3년 이하의 징역 또는 5억원 이하의 벌금 대상입니다.

| | |
| --- | --- |
| 언제 | 사용승인 신청 시입니다. |
| 무엇을 | 제출대상 자재(복합자재, 마감재료·단열재, 방화문, 방화구획 자재)의 종류·규격·성능시험 결과, 시공 위치·수량, 난연성능 확인서가 적혀 있는지 확인합니다. |

### 처음 맡았다면

- 제출대상 자재(복합자재, 외벽 마감재료인 단열재, 방화문, 내화구조·자동방화셔터·내화채움성능이 인정된 구조·방화댐퍼) 확인하기
- 성능시험 결과 첨부 확인하기
- 시공 위치·수량 기재 확인하기
- 공사감리자 확인 여부 보기

### 대상과 기준

대상

- 제출대상 자재: 1 복합자재(불연재료 양면 + 심재) 2 마감재료·단열재 3 방화문 4 방화구획 자재 또는 시설
- 제출시기: 사용승인 신청 시
- 기재내용: 자재 종류·규격·성능시험 결과, 시공 위치·수량, 난연성능 확인서

품질관리서 미제출·거짓 제출 시 3년 이하 징역 또는 5억원 이하 벌금(건축법 제108조제1항제4호)

### 업무 흐름도

STEP 1 대상 확인

제출대상 자재 확인 — 복합자재·마감재·단열재·방화문·방화구획

공사시공자 · 법 제52조의4

STEP 2 품질관리서 작성

종류·규격·성능시험, 시공 위치·수량

공사시공자 · 난연성능 확인서 첨부

STEP 3 감리자 확인⚠️ 오래 걸림

공사감리자 확인 — 시공 상태 대조

공사감리자 · 확인 서명

STEP 4 제출 · 사용승인

사용승인 신청 시 허가권자 제출 → 사용승인 처리 · 보관

허가권자(감독청) · 피난·방화구조 기준 규칙 제24조의3 · 거짓 작성·미제출 시 5년 ↓ 징역·5천만 ↓ 벌금

용어 풀이

- **복합자재** : 불연재료 양면 사이에 심재를 넣은 자재
- **심재** : 복합자재 가운데에 들어가는 속 재료
- **난연성능** : 불에 잘 타지 않는 성능
