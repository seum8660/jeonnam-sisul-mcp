# 건물 단면으로 보는 높이·깊이 기준

지면 위는 건물·가설구조물 높이, 지면 아래는 굴착 깊이 기준입니다. 같은 10m 라도 위로 쌓으면 가설구조물, 아래로 파면 안전관리계획과 유해위험방지계획서가 따라옵니다. 층수 기준(10층 안전관리계획, 16층 2종·21층 1종 시설물)은 학교에서는 드물어 그림에서 뺐습니다.
