## 79. 산지전용 — 학교 부지에 산이 있을 때

제7부 부지와 인허가 · 79

산지전용 — 학교 부지에 산이 있을 때

부지에 산이 있으면 — 면적별 협의 상대와 조성비 감면

한마디로

임야(산)를 학교 부지로 쓰려면 산지를 다른 용도로 바꾸는 「산지전용」을 거칩니다. 학교시설사업은 보통 시행계획 승인 때 산지전용허가가 의제되고, 면적과 산지 종류에 따라 협의 상대(시장·군수, 시·도지사, 산림청장)가 정해집니다. 학교 시설용지는 대체산림자원조성비가 전액 감면됩니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 보전산지는 3만 ㎡만 넘어도 협의 상대가 시·도지사로 올라갑니다(산지관리법 시행령 제15조1 1).

| | |
| --- | --- |
| 언제 | 부지에 임야가 있으면 시행계획 승인 전에 산지전용 협의를 마칩니다. |
| 누가 | 교육청이 협의 서류를 준비하고, 승인권자가 산림청장등(면적에 따라 시장·군수·구청장, 시·도지사, 산림청장)과 협의합니다. |
| 무엇을 | 산지 종류(보전·준보전)와 면적을 확인하고, 경계를 표시해 서류를 갖추고, 허가기준(재해 우려 등)과 조성비 감면을 확인합니다. |

### 처음 맡았다면

- 지목 임야 필지와 산지구분도 확인
- 보전산지 3만 ㎡ 미만인지 확인
- 전용 구역 경계 표시
- 토사 유출·붕괴 대비 재해방지계획
- 학교 시설용지 조성비 100% 감면 확인
- 청사·도서관은 100%, 수련원은 50% 감면 — 학교가 아니면 직접 허가 신청

### 대상과 기준

**학교 부지에 임야(산)가 들어 있으면** 산지를 다른 용도로 바꾸는 「산지전용」을 거칩니다. 학교시설사업은 보통 **시행계획 승인 때 산지전용허가가 의제** 되므로, 승인권자가 산림청장등과 협의하고 협의에 필요한 서류를 교육청이 준비합니다.

### 절차와 대체산림자원조성비

부지 안 산지 확인 → 경계 표시 · 서류 작성 → 산림청장등 협의(의제) → 현지조사 · 허가기준 심사 → 조성비 감면 확인 · 허가증

**산지 확인** 지목(임야)과 산지구분도(보전·준보전)를 확인 — 실제로 나무가 자라는 땅인지도 현장에서 확인

**의제 협의** 다른 법률로 산지전용허가가 의제되는 처분을 하려면 허가기준 검토에 필요한 서류를 산림청장등에게 제출해 협의, 처분 후 지체 없이 통보 (법 제14조4 5)

**심사** 구역 경계를 표시하고 신청 → 경계표시 확인 등 **현지조사** 후 허가기준 적합 여부 심사 (시행령 제15조1 2)

**허가기준** 토사 유출·붕괴 등 **재해 우려가 없을 것**, 우량한 산림·수원 함양 기능을 크게 해치지 않을 것, 산지전용 면적·방법이 적정하고 복구에 지장이 없을 것 등 (법 제18조1) — 재해방지시설 설치 조건이 붙을 수 있음(같은 조 3)

**학교는 감면** 유·초·중등·고등학교 **각급 학교의 시설용지는 대체산림자원조성비 100% 감면** (시행령 별표 5 제3호 나목) — 감면은 산림청장등이 정하며 중앙산지관리위원회 심의를 거침 (법 제19조5 6)

**허가증** 조성비 납부나 복구비 예치가 필요한 경우 그 사실을 확인한 뒤 허가증 발급 (시행령 제15조3)

### 학교가 아닐 때 — 청사·도서관·수련원 등

**의제는 「학교시설」에만 붙습니다.** 학교시설사업 촉진법 제5조 제7호의 산지전용허가 의제는 같은 법 제2조의 학교시설 사업에만 적용됩니다. 청사·공공도서관·학생수련원·관사처럼 학교시설이 아니면 **산지전용허가를 직접 신청** 합니다. 협의 상대(면적 기준)와 허가기준은 학교와 같습니다.

**해석** 산지가 일정 면적 이상이고 보전산지가 많이 포함되면 산지관리위원회 심의가 붙을 수 있습니다(법 제18조4). 학생수련원이 「청소년수련시설」에 해당하는지, 관사가 감면 대상인지, 복구비 예치 면제(시행령 제46조1) 대상인지는 관할 시·군 산림 부서와 미리 확인하세요.

원문 대조 2026. 11. 13. — 산지관리법 제14·18·19조(2026. 9. 22. 시행), 같은 법 시행령 제15·46조·별표 5(2026. 9. 18.), 학교시설사업 촉진법 제2·5조(2025. 11. 11.)

용어 풀이

- **산지전용** : 산지를 조림·숲 가꾸기 외의 용도로 쓰려고 형질을 바꾸는 것
- **보전산지** : 임업용산지와 공익용산지 — 행위 제한이 엄격
- **대체산림자원조성비** : 산지를 전용할 때 내는 비용 — 학교 시설용지는 100% 감면
