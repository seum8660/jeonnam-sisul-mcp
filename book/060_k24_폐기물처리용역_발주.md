## 24. 폐기물처리용역 발주

제3부 시공 · 24

폐기물처리용역 발주

위탁처리 건설폐기물 100톤 ↑이면 공사와 따로 맡기는 용역

한마디로

공사에서 나오는 건설폐기물을 처리할 업체를 공사와 따로 뽑아 계약하는 업무입니다. 처리비를 공사비에 섞지 않고 별도 용역으로 맡겨, 폐기물이 어디서 어떻게 처리됐는지 투명하게 관리하려는 제도입니다.

치트키 · 꼭 알아야 할 것

- **기준** 폐기물 100톤 이상 분리발주
- **놓치기 쉬운 것** 석면 같은 지정폐기물은 건설폐기물 처리용역에 섞지 않고 따로 처리 기준을 확인합니다.

| | |
| --- | --- |
| 언제 | 공사 발주 단계에서 폐기물 발생량을 보고 함께 판단합니다. |
| 무엇을 | 설계상 발생량으로 분리발주 대상인지 정하고, 처리용역을 계약한 뒤 공사 중에는 배출자로서 올바로시스템에 인계·처리 내역을 입력합니다(5톤 이상). |

### 처음 맡았다면

- 설계상 폐기물 발생량 확인 — 100톤 이상이면 분리발주
- 석면 등 지정폐기물 여부 확인
- 5톤 이상이면 올바로시스템 입력

### 대상과 기준

대상

- 건설폐기물 100톤 이상: 분리발주 대상
- 5톤 이상: 폐기물처리업체가 폐기물 처리 사항 지자체 신고
- 5톤 이상 배출자: 올바로시스템 입력
- 지정폐기물(석면 등): 별도 처리기준 확인(분리발주 의무는 위탁처리량 100톤 이상 기준)

### 업무 흐름도

STEP 1 대상 판단

발생량 100톤 ↑ · 석면 여부 확인

발주청 · 설계내역 물량

STEP 2 발주 · 계약

폐기물처리용역 분리발주 · 계약

발주청

STEP 3 신고 · 입력

처리 신고(5톤 ↑ 지자체) · 올바로시스템 입력

폐기물처리업체 · 배출자 입력 의무

STEP 4 처리 · 확인⚠️ 오래 걸림

처리 완료 확인 · 정산 → 수집·운반·처리 — 인계서 관리

발주청 · 폐기물처리업체 · 준공 서류 연계 · 계량증명서
