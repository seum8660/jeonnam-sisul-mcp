## 2. 기본안전보건대장

제1부 기획 · 2

기본안전보건대장

계획 단계 공사 위험요인·감소대책 문서

한마디로

총공사금액 **50억원 이상** 건설공사에서 발주청이 설계 전 계획단계에 "이 공사에서 무엇이 위험한가"를 미리 적어 두는 위험 목록입니다. 설계자는 이를 받아 설계로 위험을 줄이는 방법을 설계안전보건대장에 담고, 시공사는 그것을 현장에서 실행하는 공사안전보건대장을 씁니다. 세 대장이 이어지는 이어달리기입니다.

치트키 · 꼭 알아야 할 것

- **기준** 공사비 50억 이상
- **놓치기 쉬운 것** 총 공사금액은 한 공사를 위해 발주한 금액의 합 — 전기·통신·소방 등 분리발주한 공종도 합산합니다

| | |
| --- | --- |
| 언제 | 공사 발주 단계, 설계자가 설계안전보건대장을 쓰기 전에 작성합니다. |
| 무엇을 | 기본안전보건대장을 작성하고, 이후 설계자의 설계안전보건대장과 시공자의 공사안전보건대장을 검토해 적정성과 이행 여부를 확인합니다. |

### 대상과 기준

50억 원↑

총공사금액 50억 원 이상 건설공사

하나의 건설공사를 완성하려고 발주한 공사금액의 합으로 셉니다 — 분리발주한 전기·통신·소방도 합산

「산업안전보건법」 제67조, 같은 법 시행령 제55조

세 대장의 이어달리기

1 기본안전보건대장

발주청 · 계획단계(설계 전)

위험 목록 **무엇이 위험한가** 공사 개요·현장 정보·유해·위험요인과 감소방안·발주자 법령상 의무 확인

→ 설계자에게 — 설계계약 때

↓

2 설계안전보건대장

설계자 · 설계단계

위험 해결안 **설계로 어떻게 줄였나** 시공단계 감소방안·적정 공사기간·공사금액 산출서·산업안전보건관리비 산출내역서

→ 시공사에게 — 입찰 때 고지·계약 때

↓

3 공사안전보건대장

시공사 · 공사단계

현장 실행 **현장에서 지킨다** 발주청이 적정성 검토·이행 여부 확인

예시 — 운동장 옆 교사동 증축

발주청이 찾은 위험

- 학생 동선과 공사차량 동선이 겹침
- 지하 굴착이 있음
- 타워크레인 사용 예상

설계자가 내놓은 해결안

- 공사차량 출입구를 학생 동선 반대편에 배치
- 굴착은 흙막이 공법과 계측기 설치
- 무리한 작업이 없도록 적정 공사기간 산정

포함 사항: 「산업안전보건법 시행규칙」 제86조1 2

### 업무 흐름도

STEP 1 대상 판단

총 공사금액 50억 ↑(발주 공사금액 합산 기준)

발주청 · 산업안전보건법 제67조 · 시행령 제55조

STEP 2 기본안전보건대장(계획단계)

발주청이 기본안전보건대장 작성 — 설계 발주 전, 설계자에게 제공

발주청 · 고시 제3조

STEP 3 설계안전보건대장 작성(설계단계)

설계자가 설계안전보건대장 작성 — 발주청에서 받은 기본안전보건대장 내용을 반영하고, 안전보건 전문가 검토를 거쳐 발주청에 제출

설계자 · 고시 제6조

STEP 4 설계안전보건대장 확인⚠️ 오래 걸림

발주청이 설계안전보건대장 확인 — 적정성 검토 후 입찰 시 고지, 계약 시 시공사에 제공

발주청 · 검토 확인서

STEP 5 공사안전보건대장(시공단계)

시공사가 공사안전보건대장 작성 — 설계안전보건대장을 반영해 착공 전 발주청에 제출

시공사 · 고시 제3조

STEP 6 이행 확인

발주청이 공사안전보건대장 이행 확인 — 공사 중 정기 확인

발주청 · 이행 확인 기록

주의

작성으로 끝이 아님 — 설계·시공 단계 대장 검토·확인도 발주청 몫입니다

용어 풀이

- **안전보건대장** : 공사 단계별 안전보건 위험과 대책을 적은 문서
- **총 공사금액** : 하나의 공사를 완성하려고 발주한 공사금액의 합

**함께 보면 좋아요** **이런 상황에서** 학교 신축·증축·리모델링 사업을 시작해요

근거법령

- 「산업안전보건법」 제67조, 「산업안전보건법 시행령」 제55조

 대장 작성 의무 / 대상(총공사금액 50억원 이상)
- 「건설공사 안전보건대장의 작성 등에 관한 고시」(고용노동부 고시) 제3조
- 「산업안전보건법 시행규칙」 제86조1 2

 기본·설계안전보건대장 포함 사항

**사이트에서 더 보기** 휴대폰 카메라로 비추면 치트키 사이트의 「기본안전보건대장」 업무 흐름도가 열립니다.
