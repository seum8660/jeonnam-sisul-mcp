## 26. 본인증 용역 발주

제3부 시공 · 26

본인증 용역 발주

녹색건축 등 각종 인증 취득을 맡기는 용역

한마디로

설계 단계에서 받은 예비인증을 바탕으로, 공사가 끝난 뒤 ZEB·녹색건축·BF 본인증을 받기 위한 용역을 발주하는 업무입니다. 본인증을 받아야 인증 의무를 마무리할 수 있습니다.

치트키 · 꼭 알아야 할 것

- **기준** 연면적 기준
- **놓치기 쉬운 것** 인증마다 신청 시점(사용승인 후, 공사 완료 후)이 다릅니다.

| | |
| --- | --- |
| 언제 | 공사가 끝날 무렵이나 사용승인·공사 완료 후에 진행합니다. |
| 무엇을 | ZEB는 예비인증 결과로 현장실사를 거쳐, 녹색건축은 사용승인 후, BF는 공사 완료 후 본인증을 신청합니다. 연면적 10,000㎡ 이상이면 BEMS 설치확인도 챙깁니다. |

### 처음 맡았다면

- 예비인증 취득 여부 확인
- 인증 종류별 신청 시점 확인
- 연면적 1만 ㎡ 이상 BEMS 확인
- 인증 유효기간 확인

### 대상과 기준

대상

- 제로에너지건축물 인증: 예비인증 결과 토대로 현장실사 거쳐 인증(1++등급 이상 유효기간)
- 녹색건축 인증: 사용승인·사용검사 후 신청, 유효기간 10년
- BF 인증: 개별시설 공사 완료 후 신청, 유효기간 10년
- BEMS 설치: 연면적 10,000㎡ 이상 신축·별동 증축 시(한국에너지공단 설치확인)

근거법령
