## 51. 40년 경과 노후 건축물 점검

제6부 교육시설 안전점검 · 51

40년 경과 노후 건축물 점검

오래된 시설물의 정밀 안전점검과 진단

한마디로

지은 지 **40년** 이 넘은 교사·강당·체육관·기숙사·급식실(연면적 **100㎡ 이상**)은 교육청 기준에 따라 **4년** 마다 정밀안전점검을 받습니다. **40년** 기준은 법령이 아니라 교육분야 안전 종합대책(2014)에서 나온 정책 점검입니다.

치트키 · 꼭 알아야 할 것

- **놓치기 쉬운 것** 시설물의 안전 및 유지관리에 관한 특별법 대상이 아니라고 40년 경과 건물을 빠뜨리는 실수

| | |
| --- | --- |
| 언제 | 준공일 기준 40년 이 지난 건물을 4년 주기로 점검합니다. |
| 누가 | 안전진단전문기관에 용역으로 맡깁니다. |
| 무엇을 | 대상 건물을 지정해 관리하고, 4년 주기 정밀안전점검 결과로 개·보수를 계획합니다. |

### 처음 맡았다면

- 준공 40년 경과 건물 목록 작성
- 연면적 100㎡ 이상·용도(교사·강당·체육관·기숙사·급식실) 확인
- 제3종 정기점검과 일정 조정
- 안전진단전문기관 용역 발주

**짧은 주기를 따릅니다.** A~C등급은 교육청 4년, 제3종 D·E등급은 법정 2년 (시행령 별표 3 비고 5의2 — A~C등급이 될 때까지)입니다. 정기안전점검(반기 1회 ↑)은 따로 계속합니다.

정밀안전점검을 하는 해 — 정기안전점검을 한 번 줄이는 법

정기안전점검은 상반기·하반기에 한 번씩, 1년 에 2번 합니다. 정밀안전점검을 하는 해에는 **정밀안전점검을 끝낸 반기의 정기안전점검을 안 해도 됩니다.** 그래서 둘을 **서로 다른 반기** 에 잡으면 1년 에 2번(정기 1 + 정밀 1)으로 끝납니다. 예를 들어 상반기에 정기안전점검을 했다면 정밀안전점검은 하반기에 끝내세요. 둘을 같은 반기에 하면 다른 반기 정기안전점검을 또 해야 해서 3번이 됩니다.

**예시 — 00초 본관동** 1984년 준공(40년 경과) · 제3종 B등급 · 정밀안전점검은 4년 마다 하반기

| 점검 종류 | 2026 | | 2027 | | 2028 | | 2029 | | 2030 | |
| 상 | 하 | 상 | 하 | 상 | 하 | 상 | 하 | 상 | 하 |
| 정기안전점검 | **●** 4월 | 생략 | **●** | **●** | **●** | **●** | **●** | **●** | **●** 4월 | 생략 |
| 정밀안전점검 4년 마다 | — | **★** 9월 끝 | — | — | — | — | — | — | — | **★** 9월 끝 |
| 그해 점검 | **2번** | | **2번** | | **2번** | | **2번** | | **2번** | |

상 = 상반기(1~6월) · 하 = 하반기(7~12월)

● 실시 · ★ 정밀안전점검 · 파란 칸 = 정밀안전점검을 하는 해 — 9월에 정밀안전점검을 끝냈으니 그 반기(하반기)의 정기안전점검은 생략

정밀안전점검을 상반기(예: 6월 끝)에 하면서 4월 정기안전점검도 했다면, 하반기 정기안전점검을 또 해야 해 그해 점검이 3번이 됩니다.

**헷갈리기 쉬운 점** 1 기준은 시작한 달이 아니라 **끝난 달** 입니다(시행령 별표 3 비고 9). 2 상반기는 1~6월, 하반기는 7~12월입니다. 3 D·E등급은 정기안전점검이 연 3회 (2·3월, 5·6월, 11·12월)라 이 설명과 다르니 교육청과 확인하세요. 4 교육청 4년 점검(법정 의무 아님)에도 이 생략을 적용하는지는 교육청 계획으로 확인합니다. (원문 대조 2026. 11. 9.)

누가

**점검기관** 안전진단전문기관(시설물의 안전 및 유지관리에 관한 특별법 제28조에 따라 등록)에 용역

**과업지시서에 적을 것** 시설물의 안전 및 유지관리에 관한 특별법 정밀안전점검 기준(책임기술자 자격·결과보고서 제출)대로 하도록 적으세요. 제3종 시설물이면서 40년 경과 대상인 건물은 정밀안전점검을 마친 달이 속한 반기의 정기안전점검을 생략할 수 있습니다(시행령 별표 3 비고 9).
