## 2. 치트키 본체 — 7개 장

왼쪽 차례에서 장을 고르면 됩니다. 순서는 실제 업무 순서와 같습니다.

| | |
| --- | --- |
| 제1~5장 | 기획 · 설계 · 계약 · 시공 · 준공 단계별 절차와 판단 기준 |
| 제6장 교육시설안전 | 안전점검 · 인증 · 안전성평가 · 문자메시지 모음 |
| 제7장 매뉴얼 및 지침 | 매뉴얼·가이드와 지침 요약 원문 |

장 안에는 **절차 기준**, **간단 법령 체크**, **업무 프로세스**, **위임전결** 같은 탭이 있습니다. 「모두 펼치기」를 누르면 접힌 카드가 한꺼번에 열립니다.

## 3. 찾을 때는 검색창부터

맨 위 **전체 키워드 검색** 에 「VE」, 「일상감사」, 「준공검사」처럼 낱말 하나만 넣어 보세요. 해시태그를 누르면 같은 주제의 항목이 모여서 나옵니다. 용어가 낯설면 용어 검색창에 「전결」, 「ZEB」 등을 넣으면 쉬운 풀이가 나옵니다.

## 5. 이 책과 같이 쓰는 법

책에서 업무를 찾고, 같은 이름을 사이트 검색창에 넣으면 흐름도 전체와 원문 요약, 계산기가 이어집니다. 책은 출근길에, 사이트는 업무 중에 펴 두는 식입니다. 법령이 바뀌면 사이트가 먼저 고쳐지므로, 책과 사이트가 다르면 **사이트가 최신** 입니다.

## 6. 오타·질문 보내기

사이트의 의견 창에 「오타, 정정, 질문 마구마구 보내주세요」라고 적혀 있습니다. 정말 마구마구 보내셔도 됩니다. 버전 2.0의 원고는 그렇게 모입니다.
